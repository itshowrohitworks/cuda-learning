# CUDA Learning

A hands-on journey into GPU programming, CUDA C++,
computer architecture, Linux, Python and PyTorch.

## Hardware

- GPU: NVIDIA GeForce GTX 1650
- GPU Memory: 4 GB
- Architecture: Turing
- Compute Capability: 7.5

## Environment

- OS: Ubuntu 24.04 on WSL2
- CUDA Toolkit: 12.3 (upgrade planned)
- C++: C++23
- Python: 3.12 (planned)

## Learning Modules

1. Linux and Operating Systems
2. Computer Hardware and Architecture
3. Modern C++
4. CUDA Programming
5. Parallel Algorithms
6. CUDA Optimization
7. Python GPU Programming
8. PyTorch
9. Custom CUDA Extensions

## Philosophy

Understand the theory, implement the concept,
test the result, benchmark performance and document
what was learned.
